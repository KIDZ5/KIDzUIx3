# Accents — ชุดสี Accent

KIDzUIx3 มี preset สำหรับกำหนด accent ของทั้งแอปพลิเคชัน

![Preview](../../assets/foundation_color.png)

## สรุป

 | Accent | 
 | ------------------ | 
 | Blue **(ค่าเริ่มต้น)** | 
 | Red | 
 | Orange | 
 | Yellow | 
 | Green | 
 | Graphite | 
 | Pink | 
 | Purple | 

## ตัวอย่าง

```luau
application.Accent = KIDzUIx3.Accents.Red
```
