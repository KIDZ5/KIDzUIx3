# แนวทางการออกแบบอินเทอร์เฟซ

สำหรับข้อมูลเพิ่มเติมเกี่ยวกับ Human Interface Guidelines ที่ KIDzUIx3 ใช้เป็นแนวทาง โปรดดู [เอกสาร HIG อย่างเป็นทางการของ Apple](https://developer.apple.com/design/human-interface-guidelines/)

## ทำไมสิ่งนี้จึงสำคัญ?

การทำตามแนวทางการออกแบบอินเทอร์เฟซเป็นสิ่งสำคัญต่อการสร้าง UI ที่มีคุณภาพ นอกจากความสวยงามของคอมโพเนนต์แล้ว ยังต้อง **เข้าใจว่าควรใช้คอมโพเนนต์แต่ละแบบเมื่อใดและอย่างไร**

KIDzUIx3 นำแนวทาง Human Interface Guidelines ของ Apple มาใช้เพื่อให้การออกแบบมีความสม่ำเสมอ ชัดเจน และมีจุดประสงค์ *เมื่อเข้าใจหลักการเหล่านี้* คุณจะสามารถสร้างอินเทอร์เฟซที่ดูเป็นธรรมชาติสำหรับผู้ใช้ การเลือกใช้คอมโพเนนต์อย่างถูกต้องยังช่วยให้ประสบการณ์ใช้งานดีขึ้นและดูแลระบบ UI ได้ง่ายขึ้น
